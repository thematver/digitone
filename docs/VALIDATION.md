# Проверки Digitone Studio

Дата: **3 октября 2026 года**. Результаты ниже относятся к текущему Mac-приложению и подключённому Digitone II; это ещё не проверка полного плана продукта.

## Сборка и автоматические проверки

| Проверка | Результат |
|---|---|
| Автоматические тесты | **28 прошли: 26 DigitoneCore + 2 DigitoneMIDI** |
| Mac release | Компиляция и связывание прошли; `.app` создан, включая последнюю версию с диагностикой входящего канала |
| Подпись Mac-приложения | Локальная ad hoc подпись и её проверка прошли |
| Запуск Mac-приложения | Приложение запущено как нативное приложение |
| iOS arm64, deployment target 17.0 | Ядро, MIDI, UI и общая точка входа напрямую скомпилированы и связаны; проверка повторена после изменения диагностики канала |
| Xcode-проект | Структура ссылок, две цели, схемы и plist проверены |
| Полный Xcode build/install | Не подтверждён: автоматический процесс не может писать кеш диагностики манифеста в домашнюю папку |

Тесты используют искусственные данные: упаковку и проверки SysEx, разбор MIDI, NRPN, снимки и декодирование паттерна. Они подтверждают поведение кода на этих данных. Прямая компиляция iOS создаёт проверочные артефакты и не подтверждает установку или исполнение на iPhone/iPad.

## Реальный Digitone II

В обычном нативном Mac-приложении успешно выбран MIDI-вход/выход, выполнен handshake и получена версия:

| Поле | Получено |
|---|---|
| Устройство | Digitone II |
| OS | 1.10D |
| Build | 0049 |
| Слот прочитанного паттерна | A01 |
| Темп | 120 BPM |
| Swing | 50% |
| Количество декодированных нот | 0 |
| Имя звука трека 1 | KICK_SHARP |
| Имя звука трека 9 | CY SILKY |
| Длина треков 1–16 | По 16 шагов |

Чтение A01 завершилось без тайм-аута; полученный SysEx прошёл проверку контрольной суммы и структурный декодер. Экраны **«Подключение»** и **«Паттерны»** визуально проверены с этими реальными данными.

Значения ещё **не сверены с физическим дисплеем Digitone**. A01 не содержит декодированных нот, поэтому эта проверка не подтверждает чтение заполненного нотами паттерна, аккордов и отдельных velocity/length/microtiming.

## Приём параметров от ручек

Аппаратный приём CC подтверждён. При `OUTPUT CH = AUTO CH` и активном треке 1 повороты ручек поступали на **Auto Channel 10**. После выбора MIDI-канала 10 в приложении появились три известных общих параметра с отметкой **«Получено»**:

| Параметр | Сообщение | Наблюдение |
|---|---|---|
| FILTER Frequency | CC 16 | Значение обновлялось в реальном времени: 13, затем 25 |
| FLTR · F | CC 17 | Получено 0 |
| Filter envelope Attack | CC 20 | Получено 5 |

Это значения грубой MIDI-шкалы **0–127**. Подтверждены получение событий, их маршрутизация по каналу и обновление UI для этих трёх общих параметров. Приём SYN-параметров и NRPN, отправка значений в прибор и прослушивание этим тестом не проверялись.

Чтобы различие каналов было видно сразу, в UI добавлены диагностика последнего входящего канала и явная кнопка выбора этого канала. Номер активного трека нельзя использовать как автоматическое предположение о MIDI-канале.

## Экспорт и проверка реального файла

Нативное приложение успешно экспортировало [дамп A01](../captures/hardware/DN2-1.10D-0049-A01.syx). Это локальный файл в `captures/hardware`; папка captures исключена из Git.

- Размер: **114118 байтов**.
- SHA-256: `080f28ad7a0dc135fe66bafaa76008fb1a3466623ffc282c1a63a52c660bf654`.
- Offline-команда `digitone-tool inspect` успешно проверила checksum, декодировала файл и вывела **120 BPM, 50% swing, 0 нот**, 16 треков по 16 шагов; имена T1 **KICK_SHARP**, T9 **CY SILKY** совпадают с данными приложения.

Эта проверка подтверждает сохранение и повторное декодирование настоящей аппаратной передачи. Она не выполняет запись обратно в Digitone.

Реальный файл затем **повторно импортирован через UI при отключённом MIDI**. Приложение открыло A01 и показало 120 BPM, swing 50%, 0 нот и KICK_SHARP. Этот шаг подтвердил чтение сохранённого архива независимо от подключённого прибора.

## Сохранение библиотеки и перезапуск

В обычном нативном приложении сохранён снимок **«FILTER · первый снимок»**, теги **filter**, **hardware-test**, MIDI-канал **10**:

| Известный параметр | Сохранённое значение |
|---|---:|
| Frequency | 33 |
| FLTR · F | 12 |
| Filter envelope Attack | 5 |

Запись `~/Library/Application Support/DigitoneStudio/snapshots.json` подтверждена чтением JSON: `schemaVersion = 1`, сохранены три параметра. После закрытия, пересборки и повторного запуска приложения снимок остался в библиотеке. При отключённом MIDI он открылся как **черновик** с теми же тремя значениями; автоматической отправки параметров не было.

Подтверждены локальная запись, сохранность после перезапуска и загрузка частичного набора в редактор. Применение снимка на приборе, полноценный аппаратный пресет и восстановление всего звука этим тестом не проверялись.

## Ограничение командного процесса

При создании CoreMIDI-клиента из ограниченной среды автоматизации получен код **−10833**: MIDI-сервис недоступен тому процессу. При запуске нативного Mac-приложения MIDI-сервис доступен, handshake и чтение A01 выполнены. Эти два результата относятся к разным контекстам запуска; ошибка командного процесса не свидетельствует об отсутствии подключённого прибора.

CLI-чтение непосредственно с прибора командой `capture` ещё не проверено. Экспорт из нативного приложения и offline-проверка этого файла командой `inspect` выполнены.

## Остаётся проверить

- Сверить A01 с физическим дисплеем и прочитать заполненный паттерн.
- Проверить приём остальных CC-параметров и NRPN с верным MIDI-каналом; три общих CC-параметра уже получены на канале 10.
- Изменить один параметр из приложения и проверить его на приборе.
- Прослушать тестовую ноту и проверить завершение ноты.
- Проверить применение локального снимка и вариантов A/B на приборе. Локальное сохранение, перезапуск и загрузка черновика уже прошли.
- Провести отдельный цикл CLI capture/inspect. Экспорт приложения, offline-inspect и повторный импорт файла в UI без подключения уже прошли.
- Проверить отключение USB, повторное подключение и отмену ожидающего запроса.
- Установить приложение на физический iPhone/iPad и проверить USB MIDI.
- Прочитать полный текущий звук, сохранить его и подтвердить восстановление повторным чтением.

Локальные снимки остаются **частичными наборами известных параметров**. Полные аппаратные пресеты, запись паттернов и полный синк не считаются реализованными или проверенными.
